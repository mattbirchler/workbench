New in this build: answer from the project list, a clearer session screen, and redone secondary screens.

• Answer without opening the session. A row waiting on permission shows the command with Deny and Allow right on it. A row with a plain question shows its answers as buttons. The permission card inside a chat has the same larger buttons, plus "Reply instead".

• The project list leads with what needs you. The title is now a headline like "2 need you" with the rest underneath. Tap the usage strip for the full plan usage details. When your Mac offers Brain Dump, a bar at the bottom starts new work (the brain button in the toolbar is gone).

• Session header. The name and branch are on one row and the status has a full line of its own, with how full the context is on the right. It should no longer be cut down to a word or two.

• Model and permission mode in the message box. The model moved from the header into the box, next to a new pill that switches the permission mode (Ask, Accept edits, Plan and so on). While Claude is working the box says "Queue a message".

• Changed files. A finished turn lists the files it changed under it, with line counts. Tap one, or Review, to go to the project's changes.

• Type @ in a message to get suggestions for the project's files and folders.

• New Agent is a full page with the task first, Files can search the whole project, Past Sessions rows are cards, and the empty states on these screens match the rest of the app.

Things to look for: tapping Allow or Deny by accident while scrolling the list, the permission mode pill not catching up after you switch, @ suggestions that are slow or missing in a big project, and anything cramped in the new header with long project or branch names.
